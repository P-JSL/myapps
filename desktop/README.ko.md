# My Video App 1.17.0 · Windows 앱

**Windows 10/11 x64용 개인용 다운로드 앱입니다.** YouTube 다운로드는 이 데스크톱 앱에서 사용합니다. Chrome 확장 1.17.0에는 YouTube 기능이 없습니다.

## 실행과 첫 다운로드

1. `my-video-app-desktop-windows-x64.zip`을 내려받아 **폴더 전체를 압축 해제**합니다. ZIP 안에서 실행하거나 EXE만 다른 폴더로 옮기지 마세요.
2. `MyVideoApp` 폴더의 **My Video App.exe**를 실행합니다.
3. 처음 다운로드할 때 **저장 폴더를 선택**합니다. 이후 파일마다 다른 이름으로 저장하는 창 없이 해당 폴더에 자동 저장합니다. 위치는 **설정 → 다운로드 폴더**에서 변경합니다.
4. YouTube 영상 주소 또는 직접 미디어 주소를 붙여 넣고 화질·형식을 고른 뒤 **다운로드 추가**를 누릅니다.
5. 대기열에서 진행률·속도·남은 시간을 확인하고, 완료되면 **폴더 열기**로 결과를 확인합니다.

Python·yt-dlp·EJS·Deno·FFmpeg·Qt가 포함되어 있어 별도 Python 설치, Chrome 도우미 등록, 확장 ID, API 키가 필요하지 않습니다. 설치·등록 없이 폴더에서 실행하는 포터블 앱이며 실제 영상 다운로드에는 인터넷이 필요합니다. 추가 런타임을 포함하므로 확장 ZIP보다 큽니다.

## 기능과 범위

| 기능 | 동작 |
| --- | --- |
| YouTube 다운로드 | 공개 단일 VOD·Shorts를 yt-dlp로 처리. 로그인·유료 권한·DRM을 우회하지 않음 |
| 화질·저장 형식 | 제공된 최고 화질 또는 선택 해상도, 원본·MP4·WebM·MKV·MP3·M4A. 영상과 음성은 FFmpeg로 병합 |
| 대용량 영상 | 길이 제한 없이 다운로드하며 저장 공간·사이트 제공 조건의 영향을 받음 |
| 대기열 | 동시 작업 수 설정, 취소·오류·재시도, 완료 파일의 폴더 열기 |
| 기록·설정 | 사용자 계정의 내장 SQLite DB에 자동 저장. 기록을 지워도 다운로드한 파일은 유지 |
| 화면 | 밝은/어두운 테마, 키보드 조작, 긴 제목 정리, 기록 검색·상태 필터 |
| 보안 검사 | 설정에서 다운로드 후 Windows 보안 검사를 선택. 검사 불가·실패는 안전함으로 표시하지 않음 |

지원하지 않는 기능: 재생목록 일괄 다운로드, 라이브 녹화, DRM 해제, 로그인·구독 우회, 브라우저 쿠키 자동 추출. 사이트 변경·접근 조건·영상 제공 형식에 따라 일부 요청은 실패할 수 있습니다.

서명되지 않은 개인용 Windows 빌드입니다. 이 패키지에서 인증서·백신·OS 보호 설정을 변경하지 않습니다. 포함된 구성 요소의 고지와 소스 위치는 `licenses`와 `THIRD_PARTY_NOTICES.md`를 참고하세요.

## 데이터와 삭제

다운로드 파일은 사용자가 고른 폴더에 저장합니다. 기록·설정은 `%LOCALAPPDATA%\MyVideoApp\Desktop` 아래의 SQLite DB에서 관리합니다. 앱 폴더를 삭제해 프로그램을 제거할 수 있으며, 기록·설정도 지우려면 앱을 종료한 뒤 해당 사용자 데이터 폴더를 별도로 삭제합니다.

현재 빌드 및 검사 범위는 저장소의 `reports/DESKTOP_1_17.ko.md`에 기록합니다. 실제 YouTube 사이트 접근과 Windows 사용자 환경은 사이트·OS 조건에 따라 추가 확인이 필요합니다.
