# My Video App 로컬 버전 보안 검토

앱의 계정·구독·활성화·원격 규칙·광고·진단 전송 코드를 포함하지 않는 독립 엔진이다.
유료 인증을 위조하거나 DRM 접근 권한을 우회하지 않는다. 새 설치본과 현재 프로젝트에
사용하지 않는 원본 실행 코드를 남기지 않는다. 빌드 시 원본 서비스/활성화 문자열과
원본 진입점이 설치본에 유입되면 실패하도록 검사한다.

| 경계/위험 | 조치 및 검증 |
| --- | --- |
| 웹사이트가 확장 명령을 위조 | 수집기는 같은 확장 ID·HTTP(S) 탭만 허용하고 수집만 수행. 다운로드·기록·취소는 정확한 자체 화면 URL에서만 허용 |
| 과도한 메시지·오염 데이터 | 문자열/노드/깊이 한도와 순환·비정상 타입·프로토타입 키 검사 |
| 실행 가능한 주소·사용자 정보 URL | HTTP(S)만 허용하고 user:password URL 거부. 임의 로컬 파일 경로를 받지 않음 |
| 원격 목록·조각 조작 | 미디어 URL 검증, 목록/조각/바이트/시간 한도, 제어된 가상 파일명, FFmpeg file/pipe protocol whitelist |
| 암호화/DRM 접근 | HLS 키/세션 키 및 DASH ContentProtection을 처리 시작 전에 거부. 키·라이선스 서버에 요청하지 않음 |
| UI 삽입 | 외부 문자열은 textContent로 렌더링하고 화면은 로컬 스크립트와 CSP 사용 |
| 중복·동시 완료·취소 | origin-wide 시작/기록/확대 큐 잠금, 중복 주소 요청 방지, 완료 처리 직렬화, Worker 종료 |
| 파일·기록 삭제 | 큐 파일은 UUID 이름 사용. 기록 삭제는 다운로드 파일을 지우지 않음. 네이티브 취소/폴더 열기는 자체 기록의 ID만 사용 |
| 시크릿 정보 | 지속 기록과 확대 큐에 시크릿 다운로드를 보관하지 않음 |
| 원격 부가 통신 | 미디어 감지에는 추가 요청 없음. 사용자 다운로드 선택 시 해당 사이트에 요청. 제품 서버/분석 서버 없음 |

입력 한도는 총 메모리의 엄격한 상한을 증명하지 않으며 디코더/코덱 취약점 부재를
보증하지 않는다. FFmpeg Wasm과 브라우저 자체 보안에 대한 별도 감사/업데이트가 필요하다.
사이트의 정상 브라우저 세션을 사용할 수 있지만 로그인·지역·서명 만료·접근 제한은
우회하지 않는다. 사용자가 명시적으로 선택한 미디어 사이트로만 다운로드 요청을 시작한다.

브라우저 하네스는 실제 미디어 파싱·다운로드 결과·Wasm·OPFS·취소를 검사하며 Chrome
API는 테스트 대역이다. 실제 확장 설치는 이 클라우드의 관리자 정책으로 차단되었다.
서비스 워커 복원·실제 알림·다양한 사이트에서의 동작은 별도 설치 환경에서 추가 검증해야 한다.
