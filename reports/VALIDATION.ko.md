# My Video App 1.1.0 로컬 버전 검증

환경: Node.js 24.19.0, Chromium 154.0.8037.57, Linux x86_64.
브라우저 하네스의 미디어 처리·Worker·Wasm·OPFS·파일 출력은 실제 실행한다.
Chrome 확장 API는 테스트 대역이며 실제 설치 전체가 통과했다는 의미가 아니다.
현재 단위 테스트 22개와 브라우저 하네스 시나리오 24개가 모두 통과했다.

| 항목 | 결과/범위 |
| --- | --- |
| TypeScript | 엄격한 타입 검사 통과 |
| 현재 앱 단위 테스트 | 공통 입력 검증, 확대 정책, 로컬 URL/파일명/발신자, HLS 계획·범위·암호화 차단, 네트워크 한도/취소 검사 |
| 독립 설치본 | 자체 background/content/offscreen/UI 진입점. 원본 계정·활성화 엔진과 원본 key/업데이트 URL 없음 |
| 일반 MP4 | 감지된 파일을 실제 브라우저 다운로드로 저장. 입력과 SHA-256 동일. Chrome API 부분은 대역 |
| HLS VOD | 실제 로컬 FFmpeg Wasm으로 단일/마스터/별도 오디오/바이트 범위 스트림을 MP4로 저장. H.264/AAC, 영상 프레임 수와 길이 확인 및 전체 디코드 |
| 정적 DASH VOD | 실제 XML 계획/SegmentTimeline/조각 다운로드/MP4 로컬 합성. 영상·음성 트랙과 프레임/길이 확인 및 전체 디코드 |
| 접근 제한 | 암호화 HLS와 DASH ContentProtection을 거부. 키·라이선스 서버 요청 없음 |
| 감지와 발신자 | DOM 수집은 다운로드를 시작하지 않음. 웹페이지의 다운로드·기록·상승 권한 명령과 다른 확장 ID 거부 |
| 기록·중복·취소 | 완료·중복 완료 이벤트·동시 같은 주소 요청·취소 명령·기록 삭제·재시작 시 중단 작업 정리. Chrome API 대역 사용 |
| 업스케일링 | PNG 2x/4x, 영상 2x, 원본 바이트 보존, H.264/AAC 음성/프레임/길이 확인 |
| 자원/잘못된 입력 | HTML 위장 MP4 거부, 과도한 크기 거부, 실제 Worker 취소 후 다음 작업 성공 |
| 복사 큐 | 성공 파일·실패/시크릿 제외·선택·동시 탭 잠금·기능 끄기·TTL·실제 OPFS 삭제 |
| 새 앱 통신 | 테스트용 localhost 미디어 외 요청 0, 페이지 오류 0. 부가 제품 서버 요청 없음 |
| 패키지 | 현재 빌드 해시와 브라우저 결과가 일치해야 ZIP 생성 가능. 네 개의 새/호환 ZIP과 SHA256SUMS 제공 |
| 실제 확장 설치 | 관리자 정책으로 unpacked 확장 로드 차단. 정책 우회하지 않음. 실제 Chrome 알림/서비스 워커 수명/다양한 사이트 통합은 미검증 |

실행 가능한 검사: `npm run verify`. 실제 수행 결과의 시나리오와 빌드 해시는
`reports/browser.json`, 설치 구성은 `reports/build.json`에 있다. 기존 원본 전용
구현을 제거하면서 해당 구현에만 의존하던 과거 비교 테스트도 제거했고, 현재
로컬 엔진과 공통 구성요소의 검사를 유지/추가했다. 실패한 검사를 생략한 것은 아니다.

실서비스 사이트별 로그인·서명·지역·CDN 호환성, 모든 HLS/DASH 변형, 라이브/DRM,
원본의 모든 전용 기능은 동등성 보장 범위가 아니다. 지원 범위는 `LOCAL_MODE.ko.md` 참조.
검증용 입력/출력·화면은 `test-results`에 있으며 설치/소스 ZIP에 포함하지 않는다.
