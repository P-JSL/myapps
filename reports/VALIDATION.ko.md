# 검증 결과

검증 환경: Node.js 24.19.0, Chromium 154.0.8037.57, Linux x86_64.
이 보고서의 단위 테스트와 실제 브라우저 하네스 테스트는 구분해서 해석해야 한다.

| 단위/회귀 테스트 | 32개 통과, 실패/스킵 0 | `npm test` |
| 원본 대비 브리지 결과 | 통과 | YouTube, Vimeo, iQ, Bilibili .com/.tv, Javrank; 정상 입력과 요청 메시지 비교 |
| 원본 파일 무결성 및 빌드 패치 | 통과 | 원본 81개 해시 보존, 설치본에서 65개 동일·14개 의도적 변경·스토어 메타데이터 2개 제외 |
| 실제 Chromium 하네스 | 12개 통과 | Chrome API 부분은 테스트 대역, 아래 나머지 구성요소는 실제 실행 |

브라우저 측 상세 결과: `reports/browser.json`.
원본 워커 바이트 검증 상세: `test-results/original-worker.json`.
검증용 입력/출력과 화면: `test-results/` (소스/설치 ZIP에는 포함하지 않음).

원래 다운로드 엔진과 UI 보존, 특정 브리지의 메시지 동등성, 새 업스케일링 동작에
대한 증거가 있다. **전체 기능·모든 사이트·바이트 결과의 완전 동일성이나
취약점 부재를 입증한 결과는 아니다.** 전체 독립 재작성을 위해서는 개발 원본과
사이트별 회귀 자료가 필요하며, 완전한 설치 통합 검증은 정책이 허용된 Chrome
프로필에서 수행해야 한다.
