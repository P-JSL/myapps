# 1.14.1 아이콘 팝업 배치 개선

기본 팝업을 **640×600 → 720×600px**로 넓혔다. Chrome 팝업의 최대 너비 800px 안에서 가로 공간을 늘리고, 화면이 더 작으면 화면 너비·높이에 맞춘다.

| 항목 | 이전 | 변경 |
| --- | --- | --- |
| 미디어 카드 높이 | 72px | 약 53.36px |
| 카드 사이 간격 | 10px | 6px |
| 제목 글씨 | 13px | 12px |
| 출처·크기 글씨 | 11px | 10.5px |
| 카드 아이콘 | 38×42px | 32×32px |
| 다운로드·주소 복사 | 최소 35px 높이 | 최소 32px 높이 |

제목과 출처는 한 줄 말줄임으로 표시하며 마우스를 올리면 전체 내용을 볼 수 있다. 제목 전체는 DOM과 다운로드·복사 버튼의 접근성 이름에도 남긴다. 큰 파일의 크기는 긴 MB 수치 대신 기존 공통 GiB 표기를 사용한다.

헤더·하단 도구·미디어 감지 안내의 여백도 줄였다. 너비 420px 이하에서는 카드의 버튼을 다음 줄로 배치하고, 감지 안내는 한 줄로 정리해 미디어 영역을 확보한다. 보안 검토 안내는 계속 표시하며, 긴 오류 메시지는 내용 전체를 유지한 스크롤 영역으로 제공한다.

실제 Chromium에서 긴 제목·출처와 여러 카드, 안전한 문자 렌더링, 카드와 버튼 경계, 목록 스크롤, 보안 안내와 긴 오류가 함께 있는 화면을 검사한다. 720·640·480·400·360px 너비와 500·600px 높이를 확인하며 최종 측정값은 `popup.json`에 있다. 팝업 기능·저장 설정·시크릿 격리·주소 복사 검사도 유지한다. 실제 확장 설치는 관리자 정책으로 차단돼 Chrome API는 대역이며 화면·IndexedDB는 실제 브라우저에서 실행한다.
