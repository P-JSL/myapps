# My Video App 분석 및 로컬 전환

최초 입력은 Video Download Helper 10.6.1.2의 81개 배포 파일이었다.
입력 ZIP의 SHA-256은 `705182c167510a908243295819766d9d725db0f1dc84617015ce9331663ec4cc`이다.
초기 버전은 원본 엔진을 보존한 부분 재작성으로, 이후 독립 개인용 앱 요청에 따라
버전 1.1.0부터 원본 서비스·구독·활성화·전용 추출기 코드를 제거했다.

현재 설치본은 자체 TypeScript 서비스 워커, DOM/응답 헤더 미디어 수집,
브라우저 다운로드 API, 로컬 기록, 비암호화 HLS/DASH VOD 계획/처리,
FFmpeg Wasm 기반 로컬 합성·업스케일링으로 구성된다. 원본 프로그램의 유료 권한
판정을 바꾸거나 유료 기능을 기본 활성화하는 방식은 사용하지 않는다.

TypeScript를 사용해 브라우저 확장 API 호환성을 유지하고 메시지 경계·파일 수명·
자원 한도를 타입과 런타임 검증으로 표현했다. FFmpeg/코덱은 패키지에 포함된 Wasm을
사용하며 원격 실행 코드, 원격 동작 규칙, 별도 앱 계정 서버를 사용하지 않는다.

1.2.0은 최고화질/해상도 선택, MP3/M4A 다운로드, 로컬 영상·음성 변환과 별도 트랙
병합을 독립 구현했다. 원본 안내에서 확인한 유료 혜택과 대응 범위는 `FEATURES.ko.md`에
기록한다. 기존 프로그램의 유료 판정 코드를 재사용하거나 변경하지 않는다.

1.3.0은 다운로드 준비 대기열, 취소, 일시적 네트워크 오류 복구, 공통 바이트 한도를
갖춘 최대 3개 조각 병렬 전송과 실제 ALPN 관측을 추가했다. HTTP/3는 Chrome의
정상 HTTPS 전송 경로를 사용한다. 범위와 실제 시험 조건은 `DOWNLOADS_HTTP3.ko.md` 참조.

현재 동작/제한은 `LOCAL_MODE.ko.md`, 검증은 `VALIDATION.ko.md`, 보안은 `SECURITY.ko.md`에
기록한다. 원본 엔진과 최초 분석 자료는 Git 이력의 `806ef92`에서 확인할 수 있다.
`original-hashes.json`은 과거 입력의 해시 기록이며 현재 앱의 라이선스/인증 데이터가 아니다.

## 1.4.0 로컬 백신 연동

완료 파일의 실제 경로는 Chrome downloads API에서만 가져와 별도 Python native messaging 도우미에 전달합니다. 도우미는 로컬 ClamAV 또는 기존 오프라인 정책의 Defender로 검사합니다. 감염·미검사·Chrome 경고를 완료와 분리해 저장하며, 사용자 확인 뒤에만 유지·삭제를 진행합니다. 자동 업스케일링 복사본은 검사 파일과 SHA-256·크기가 같아야 합니다. 자세한 범위는 `SECURITY_DOWNLOADS.ko.md` 참조.
