# 1.14.0 기능을 유지한 배포 경량화

비교 기준은 1.13.0의 커밋 `709a40f83542717b6b625641440a5caebb1cfa7b`이다. 앱 JavaScript는 288,971바이트, 전체 설치 리소스는 10,763,869바이트, 설치 ZIP은 10,460,511바이트였다. 이 중 gzip으로 압축한 FFmpeg 엔진의 암호문이 10,257,790바이트여서 설치 용량의 대부분을 차지했다. 최종 측정과 검증 연결 정보는 `lightweight-build.json`과 `release-validation.json`에 기록한다.

| 측정 대상 | 1.13.0 | 1.14.0 | 감소 |
| --- | ---: | ---: | ---: |
| 설치 ZIP | 10,460,511바이트 | **7,550,564바이트** | **27.82%** |
| 전체 배포 리소스 | 10,763,869바이트 | 7,883,294바이트 | 26.76% |
| 앱 JavaScript 합계 | 288,971바이트 | **171,634바이트** | **40.61%** |
| 엔진 압축 페이로드 | 10,257,774바이트 | 7,280,521바이트 | 29.02% |

설치 ZIP과 전체 리소스 값에는 새 디코더·필수 라이선스·주소 복사 기능을 포함한다. 앱 JavaScript는 vendor를 제외한 진입점 9개와 공유 모듈 15개의 합계다. 디코더는 Wasm 208,439바이트와 래퍼 JS 9,387바이트이며 엔진의 암호화 태그 16바이트도 전체 리소스에 포함한다. 압축 전·후 파일 수가 달라도 같은 기능 범위를 비교한다. 설치 ZIP의 예상 바이트와 실제 패키징 바이트가 같아야 최종 검증을 완료한다.

## 적용한 방법

- **공통 ESM 코드 분리:** 앱·팝업·백그라운드·Worker가 공유하는 코드를 빌드 시 한 번 출력한다. 콘텐츠 스크립트는 기존 독립 IIFE를 유지한다. 모든 공유 파일도 배포 경로 변환과 검증 목록에 포함한다.
- **UTF-8 출력:** 이미 UTF-8인 한국어 UI 문자열을 반복된 `\uXXXX` 대신 문자 그대로 출력한다. Chrome 120 대상 문법과 문자열 값은 유지한다.
- **같은 이미지 한 번 저장:** 바이트가 완전히 같은 두 PNG 아이콘은 한 실제 파일을 공유한다. 문맥에 따라 상대 경로·실행 의미가 달라지는 JS·CSS·HTML은 이미지처럼 합치지 않는다.
- **엔진은 원본 바이트 보존:** FFmpeg 기능·코덱을 삭제하지 않고 배포 압축 방식을 개선한다. 압축 해제된 엔진 SHA-256은 기존 고정 코어와 같아야 한다. 새 런타임 압축 해제 모듈과 라이선스도 설치본에 포함하며 외부에서 실행 코드를 받지 않는다.
- **ZIP 최고 압축 적용:** 사용자 지정 `ZipInfo`를 쓸 때 전역 압축 설정이 전달되지 않던 부분을 수정해 각 파일에 DEFLATE level 9를 명시한다. 실제 멤버 바이트를 독립 zlib 결과와 비교하며 날짜·파일 모드·CRC·별칭을 유지한다.
- **팝업 반복 검사 줄이기:** 목록 표시 때 진행 중인 URL 집합을 한 번 만들어 미디어×기록 반복을 미디어+기록 처리로 바꾼다. 실제 다운로드 클릭에서는 최신 기록을 다시 확인한다.

앱 진입점의 공개 export는 계속 0개다. 공유 ESM 파일 사이에는 빌드가 생성한 짧은 내부 export/import가 필요하며, 별도 공유 모듈 목록과 연결 그래프를 검사한다. 엔진·압축 해제 모듈의 필요한 인터페이스도 별도로 구분한다. 웹페이지에 허용하는 API나 `externally_connectable`, 권한, CSP를 확장하는 방법은 사용하지 않는다. 클라이언트 복호화 키가 설치본에 포함돼 추출 가능하다는 기존 한계는 유지한다.

## 조사와 추가 기능

공식 저장소 다섯 개를 고정 리비전으로 비교했다. 현재 앱에 있는 병렬 다운로드·화질·오디오·재시도·디스크 병합을 중복 구현하지 않고, 작고 유용한 **주소 복사**를 팝업과 전체 앱에 독립 구현했다. 사용자가 누를 때만 HTTP(S) 미디어 URL을 복사하며, 거부되면 직접 선택·복사할 수 있는 읽기 전용 창을 연다. 클립보드를 읽지 않고 새 권한·외부 서비스도 추가하지 않는다. [도구별 근거와 보류한 기능](COMPETITOR_RESEARCH.ko.md)을 참고한다.

## 측정 범위와 한계

설치 ZIP 크기, 압축 전 배포 리소스 크기, 모든 앱 JavaScript 합계를 별도로 비교한다. 공통 파일을 여러 진입점에 중복 합산하거나 공유 코드 크기를 제외해 절감률을 부풀리지 않는다. 의도적으로 무작위 키·nonce·파일명을 사용하는 빌드이므로 매 빌드의 전체 해시는 달라진다. 브라우저·HTTP/3 검증과 ZIP은 같은 최종 빌드에 연결한다.

크기 감소가 모든 다운로드·인코딩의 속도 향상을 뜻하지 않는다. 더 강한 엔진 압축은 빌드 시간과 실행 시 압축 해제 모듈·임시 메모리 비용을 추가한다. FFmpeg 본체의 32,232,419바이트 실행 코어와 영상 처리 메모리 요구는 줄이지 않는다. 기존 로컬 처리·백신·정적 검사·암호화 스트림 차단과 변환별 자원 한도는 유지한다. 실제 설치 확장 API·Windows 백신과 모든 Chrome 버전의 실기기 검증이라는 기존 범위 제한도 유지한다.


## 1.14.1 팝업 배치 패치

컴팩트 팝업을 포함한1.14.1의 현재 값은 앱 JavaScript171,630바이트, 전체 배포 리소스7,884,687바이트, 설치 ZIP7,550,915바이트다. 1.13.0 대비 설치 크기 감소는 약27.81%이며, 위1.14.0 표는 해당 버전의 역사적 측정으로 보존한다. 공유 코드·Brotli·보안 검사 방식은 유지한다. 팝업 너비·카드 밀도와 작은 화면 검사는 `POPUP_COMPACT.ko.md`와 `popup.json`에서 확인한다.

## 1.15.0 저장 폴더 설정 추가

최초 저장 폴더 확인과 자동 저장 UI를 포함한 현재 배포는 앱 JavaScript 177,902바이트, 전체 리소스 7,894,513바이트, 설치 ZIP 7,553,359바이트다. 1.14.1 대비 앱 JavaScript는6,272바이트, 설치 ZIP은2,444바이트 증가했다. 기존 경량 포장과 동일 엔진을 유지하며 추가 네이티브 쓰기 도우미나 권한을 넣지 않는다. 위 이전 버전 수치는 역사적 측정으로 보존한다. 최신 해시는 lightweight-build.json과 release-validation.json을 참고한다.

## 1.16.0 YouTube 지원 추가

YouTube 클라이언트·설정·출처 검증·원본 트랙 병합을 포함한 현재 앱 JavaScript는 191,875바이트, 전체 리소스는 7,918,102바이트, 설치 ZIP은 7,562,311바이트다. 1.15.0 대비 앱 JavaScript는13,973바이트, 설치 ZIP은8,952바이트 증가했다. YouTube 도우미 ZIP은15,718바이트이며 yt-dlp·EJS·Deno 바이너리/패키지는 확장이나 도우미 ZIP에 넣지 않는다. 도우미가 별도 설치된 고정 의존성을 사용하며 기존 엔진·Brotli 포장·보안 경로를 유지한다. 위 이전 버전의 수치는 해당 버전 측정으로 보존한다.
