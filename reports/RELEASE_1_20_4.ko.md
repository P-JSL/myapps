# 1.20.4 · MissAV 확장 다운로드 처리 시간 개선

MissAV 확장의 Chrome 메시지로 받은 Base64 데이터를 바이트 배열로 바꾸는 구간을 최적화했다. 바이트마다 콜백과 문자열 반복자를 실행하던 방식을, 필요한 크기의 배열을 한 번 만들고 인덱스로 채우는 방식으로 바꿨다. Chrome 120 이상에서 사용할 수 있는 기존 API만 사용한다.

128KiB 메시지 상한, 원본 탭과 영상 UUID의 요청 범위, 데이터 검사, 오류 처리, 취소와 병렬 작업 수는 유지한다. 일반판의 수집기·백그라운드와 Windows 다운로드 엔진은 변경하지 않았다. 제품 버전과 설치 폴더를 함께 갱신한다.

## 실제 전체 다운로드 비교

[Windows 실행 결과](https://github.com/P-JSL/myapps/actions/runs/44084167377)에서 게시된 v1.20.3 ZIP과 수정판 커밋 `9e0999e56a3bff484f3c4b3e306594897778df6d`를 같은 Windows 러너·Chromium 156.0.8078.4에서 비교했다. 각 실행은 새 브라우저 프로필을 사용한다. 순서는 기존판·수정판·수정판·기존판이다.

측정은 실제 주소 입력 폼 제출 직전부터 Chrome이 최종 파일을 완전히 저장할 때까지다. 네트워크 수신·조각 처리·병합·저장을 포함한다. 측정 후 파일 해시와 미디어를 검사하므로 검증 비용은 시간에 포함하지 않는다.

| 순서 | 버전 | 저장 시간 |
| --- | --- | ---: |
| 1 | 기존판 | 275.76초 |
| 2 | 수정판 | 180.81초 |
| 3 | 수정판 | 161.03초 |
| 4 | 기존판 | 271.89초 |
| 평균 | 기존판 → 수정판 | 273.82초 → 170.92초 |

평균 저장 시간이 **37.58% 줄었다**. 수정판의 가장 느린 결과도 기존판의 가장 빠른 결과보다 5% 이상 빨랐다. 각 버전 두 번, 한 컴퓨터와 한 영상의 결과이므로 다른 회선·사이트·PC에서도 같은 비율을 보장하지 않는다. 일반판·데스크톱·YouTube 속도를 측정한 결과도 아니다.

네 번 모두 비암호화 VOD 921구간, 실제 미디어 응답 923건 성공·실패 0건이다. 최종 파일은 1,974,360,037바이트, 3,682.965333초이며 영상·음성과 처음·끝의 디코딩을 확인했다. 네 파일의 SHA-256은 모두 `63836dd54a9c26beb61d47344d8d25e02bec2832e5015144e991f49231eac893`이다. [측정 JSON](DOWNLOAD_SPEED_COMPARISON.json)에 빌드 해시와 원본 수치를 보관했다.

원본 MissAV 페이지에서 사용자가 제공한 m3u8를 실제 요청해 감지한 뒤 확장의 주소 폼에서 다운로드했다. 페이지를 여는 것만으로 해당 영상이 자동 감지됐다고 확대하지 않는다. 영상 파일은 검사 후 삭제하고 배포하지 않는다.

## 빌드와 릴리즈

기본판은 `extensions/standard/`, MissAV판은 `extensions/missav/`에 각각 커밋한다. 릴리즈는 두 확장 ZIP과 양쪽 경로를 지원하는 Windows 통합 앱을 제공한다. Windows GUI·각 확장 UI·설치된 MissAV 확장·최종 릴리즈 빌드의 실영상 전체 저장·ZIP 해시 검사를 통과한 커밋만 게시한다. 실제 결과는 릴리즈의 검증 JSON과 체크섬에 기록한다.

추가 최적화는 별도로 검토하며, 이 릴리즈의 성능 수치는 위 한 가지 데이터 변환 변경에 대한 결과다.
