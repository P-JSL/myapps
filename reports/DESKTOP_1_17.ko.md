# 1.17.0 · Chrome 확장과 Windows 앱 분리

기준은 사용자가 복원한 **1.16.0**입니다. 1.16.1을 다시 넣지 않았습니다. 1.17.0에서는 YouTube를 확장에서 제거하고 별도 Windows x64 GUI 앱으로 이동했습니다.

## 제공 파일과 실제 기능

| 제품 | 제공 내용 |
| --- | --- |
| Chrome 확장 | 일반 미디어·HLS/DASH 감지/다운로드, 자동 저장, 기존 로컬 미디어 도구와 선택적 백신 연동. YouTube 주소·재생 조각은 거부하며 데스크톱 앱으로 안내 |
| Windows 앱 | 공개 단일 YouTube VOD·Shorts와 직접 미디어 주소, 최고/선택 화질, MP4/WebM/MKV·MP3/M4A, 영상·음성 병합, 대기열·취소·재시도, SQLite 기록·설정 |

Windows 앱은 Python 3.13.17, yt-dlp 2026.10.21, EJS 0.8.0, Deno 2.9.8, Qt/PySide6 6.12.0, FFmpeg 9.0.2-36-g6882969ce9를 포함합니다. 고정 URL·SHA-256·공식 배포 메타데이터와 라이선스 고지를 보존합니다. 앱 실행 시 별도 Python 설치·브라우저 도우미 등록·API 키는 필요하지 않습니다.

앱은 약 236MB ZIP, 압축 해제 후 약 604MB입니다. 8KB 네이티브 Windows GUI 실행 파일이 포함된 Python을 절대경로로 실행합니다. 런타임과 GUI DLL을 포함하므로 확장 ZIP보다 크며, Git 파일 크기 제한을 넘는 앱 ZIP은 Release에만 첨부합니다.

## GUI 설계와 검토

공식 Open Video Downloader·XDM·yt-dlg·Tartube 문서와 화면을 참고해 **주소 입력 → 저장 형식/화질/폴더 확인 → 다운로드** 순서를 사용했습니다. 제3자 앱 코드를 복사하지 않았으며 객관적으로 보편적 최상의 GUI라는 주장은 하지 않습니다.

- 읽기 쉬운 한국어, 밝은/어두운 테마, 일관된 사이드바와 주 동작 버튼.
- 긴 제목 생략, 명확한 상태·오류·진행률·속도·남은 시간, 키보드 조작.
- 최초 폴더 선택 후 파일마다 저장 창 없이 저장, 검색 가능한 기록과 설정 분리.
- 창 최소 크기 1000×700 및 일반 1220×860에서 정렬·스크롤 확인.

## 검토 중 수정한 문제

새 작업 UUID가 재시도로 해석되어 첫 다운로드가 실패하던 문제, 최초 기본 폴더 미생성, 화질/형식 설정 저장 누락, 드롭다운 표시, Python 시작 실패 시 무응답을 수정했습니다. 앱 중복 실행이 기존 DB 작업을 변경하지 않도록 DB 초기화 전에 사용자 데이터 폴더별 잠금을 획득합니다.

고정 런타임·출력 폴더를 검증하고 셸 명령·브라우저 쿠키·외부 플러그인·API 키를 사용하지 않습니다. 다운로드/미디어 처리 중 취소, 추출기/Deno 자식 프로세스 정리, 안전한 파일명·덮어쓰기 방지·소유한 임시 폴더 정리, 실행 파일·HTML 위장 거부, 검사 불가/실패의 명시적 표시를 적용합니다. YouTube 원본 주소만 기록하고 서명된 트랙 주소·인증 헤더는 로그나 DB에 저장하지 않습니다.

## 집중 검사 범위

사용자 요청에 따라 **기존 전체 단위·브라우저·HTTP/3·백신·성능 검사를 반복하지 않았습니다.** 새 확장 분리 4개, 데스크톱 엔진 26개, Qt GUI/DB/대기열 6개, 패키지 빌더 10개, 네이티브 실행 파일 5개, 변경된 아카이브 계약 5개, Release 게시 12개 검사를 수행했습니다. 타입 검사와 두 제품의 빌드·ZIP 무결성·전체 앱 파일 해시도 확인했습니다. 최신 해시는 `release-validation.json`, `build.json`, `desktop-build.json`을 기준으로 합니다.

실제 yt-dlp 2026.10.21과 Linux FFmpeg/ffprobe로 로컬 합성 H.264/AAC 영상을 MP4·MP3·M4A로 저장하고 스트림·길이·DB 완료·임시 파일 정리를 확인했습니다. Qt GUI 검사는 실제 창·스레드·신호·SQLite를 사용하고 네트워크/의존성 경계를 대역으로 바꿉니다. Windows 실행 파일은 Linux에서 실제 C 진입 함수의 Win32 대역 검사와 PE/가져오기 분석을 수행했습니다.

실제 Windows 런타임 검사는 Release 작업에서 패키지의 Python·Qt·yt-dlp·FFmpeg를 실행해 수행하며 **GUI·대기열·로컬 MP4/MP3/M4A 검사가 통과해야 게시**합니다. 그 결과는 Release의 `WINDOWS-VALIDATION.json`에 별도로 첨부합니다. 로컬 빌드 보고서의 Windows 실행 미검증 표시는 이 클라우드에서 수행한 정적 검사 범위를 뜻합니다.

## 확인하지 못한 범위

클라우드 정책상 실제 YouTube 서버 다운로드와 사용자 PC의 Defender·대화형 Windows 표시를 검증하지 못했습니다. DRM·로그인/유료 권한 우회·라이브 녹화·재생목록 일괄 저장은 지원하지 않습니다. 제공 형식·접근 조건·사이트 변경으로 일부 영상은 다운로드가 제한될 수 있습니다.

Hitomi Downloader 공식 저장소는 조사 당시 HTTP 451로 소스를 확인할 수 없었습니다. 이 앱의 내장 방식은 공식 Python/yt-dlp/Qt/FFmpeg 배포물을 이용한 독립 구현이며 Hitomi 코드를 복제하거나 현재 구현을 검증했다고 주장하지 않습니다.
