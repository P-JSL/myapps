# 1.20.5 · MissAV 확장의 데이터 인코딩 최적화

MissAV 확장이 Chrome 메시지로 보내는 미디어 데이터를 Base64로 바꿀 때, `Reflect.apply`로 최대 8,192바이트 뷰를 전달한다. 바이트 배열을 스프레드할 때 발생하는 반복 비용을 줄이고, 같은 문자 변환과 `btoa`를 사용한다. 메시지는 최대 128KiB이며, 원본 탭과 영상 UUID의 요청 범위, 취소, 데이터 검사 규칙이 기존대로 적용된다. Chrome 120 이상에서 로드할 수 있다.

같은 Windows 러너에서 Chromium 156.0.8078.4와 비암호화 61분 영상 하나를 사용했다. 각 다운로드마다 새 브라우저 프로필을 만들고, 원본 탭에서 제공받은 m3u8를 요청한 뒤 확장 주소 폼에서 저장을 시작했다. 폼 제출부터 Chrome의 전체 파일 저장 완료까지 측정하고, 그 뒤 해시와 미디어를 검사했다. 기준판의 전송 코드는 v1.20.4에 들어간 디코딩 최적화와 동일하다. 평균 저장 시간이 **132.75초에서 114.10초로 14.0% 줄었다.** 네 번 모두 미디어 응답 923건이 성공했으며, 1,974,360,037바이트의 같은 파일을 저장했다. 재생 시간 61분 22.965초와 H.264 1080p 영상·AAC 음성, 처음과 끝의 디코딩을 확인했다. 네 파일의 SHA-256은 `63836dd54a9c26beb61d47344d8d25e02bec2832e5015144e991f49231eac893`이다.

각 방식 두 번씩, Windows 러너 한 대에서 얻은 MissAV 확장 측정값이다. 사이트와 회선에 따라 달라진다. v1.20.4의 37.58% 단축은 다른 러너에서 수행한 이전 비교 결과다. [이전 비교](RELEASE_1_20_4.ko.md)

일반판과 MissAV판은 각각 `extensions/standard/`와 `extensions/missav/`에서 설치할 수 있다. Windows 통합 앱은 일반 미디어·YouTube·MissAV를 지원한다. 릴리즈의 설치 파일 세 개와 검증 결과는 GitHub에서 받을 수 있다. [v1.20.5 릴리즈](https://github.com/P-JSL/myapps/releases/tag/v1.20.5)
