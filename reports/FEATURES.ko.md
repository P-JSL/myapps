# My Video App 1.16.0 · 로컬 미디어 기능

사용자가 선택한 범위는 최고화질·오디오 저장·변환·병합 모두이다.
원본 ZIP의 영어 안내에서 `get_premium_description`은 무제한 다운로드와 최고 화질을,
`premium_yt_required_description`은 비구독 YouTube 다운로드의 2시간 간격을 설명한다.
이는 안내 문자열에서 확인한 범위이며 원본의 모든 버전·유료 기능 분류를 증명하지 않는다.
오디오 저장 메뉴도 확인했지만 그 메뉴 자체가 유료라는 증거로 취급하지 않는다.

현재 앱은 독립 TypeScript/FFmpeg Wasm 구현이며 앱 계정·구독·활성화 코드가 없다.
사용 횟수·날짜별 과금 제한이나 상업적 대기시간을 두지 않는다. 아래의 용량·시간 한도는
브라우저의 자원 소진을 줄이기 위한 처리 한도이다. 원본 유료 권한을 위조하지 않는다.

| 기능 | 로컬 앱의 동작 |
| --- | --- |
| YouTube 영상·Shorts | 별도 로컬 yt-dlp/Deno 도우미 설치 후 공개 단일 VOD의 실제 영상·음성 주소를 추출한다. 최고/2160/1080/720/480 화질과 MP3/M4A를 선택하고, 확장이 MP4/WebM/MKV로 코덱 복사 병합하여 기존 저장 폴더·위험 검사 경로로 저장한다. 설치는 YOUTUBE.ko.md를 참고한다. |
| 미디어 주소 복사 | 팝업·전체 앱에서 감지 항목의 **주소 복사**를 누른다. 사용자가 누른 주소만 클립보드에 쓰며 브라우저가 허용하지 않으면 표시된 주소를 직접 선택·복사한다. 클립보드를 읽거나 자동으로 복사하지 않으며 추가 권한·외부 서버가 필요하지 않다. |
| 최고화질/해상도 선택 | HLS/DASH의 선언된 영상 높이를 우선하고 동률이면 대역폭을 비교한다. 최고/2160/1080/720/480을 선택한다. 상한 이하가 없으면 가장 낮은 제공 높이, 높이 정보가 전혀 없으면 최대 대역폭 트랙을 사용한다. 미디어 파일 하나에는 선택할 변형이 없으므로 원래 파일을 저장한다. |
| 오디오 다운로드 | 감지한 일반 파일·비암호화 HLS/DASH에서 MP3 또는 M4A(AAC) 192kbps로 저장한다. 외부 음성 트랙이 있으면 가능한 경우 영상 조각을 가져오지 않는다. 음성 트랙이 없으면 오류를 표시하며 영상 파일을 음성 확장자로 저장하지 않는다. |
| 로컬 영상 변환 | MP4/MKV는 H.264/AAC, WebM은 VP8/Opus로 변환한다. 원본 크기 또는 최대 높이를 선택하며 작은 영상을 확대하지 않는다. 일반적으로 첫 영상·첫 음성을 사용한다. |
| 오디오 추출/변환 | 로컬 영상·오디오의 첫 음성을 MP3/M4A 192kbps 또는 WAV PCM 16-bit로 저장한다. 원래 손실 압축에서 WAV를 만들어도 사라진 음질이 복원되지는 않는다. |
| 별도 영상/음성 병합 | 영상과 별도 음성 파일을 선택하여 MP4/MKV로 저장한다. 영상은 코덱 복사하고 선택한 음성은 AAC로 변환한다. 기존 영상의 음성은 대체하며 짧은 트랙의 길이까지 저장한다. 컨테이너와 영상 코덱이 맞지 않으면 먼저 영상 변환을 사용한다. |
| 업스케일링 | 기존 이미지/영상 Lanczos 2x/4x와 다운로드 완료 복사 큐를 유지한다. 모든 도구는 별도 결과를 만들며 원본을 덮어쓰지 않는다. |

다운로드 화면에서 **스트림 화질·저장 형식**을 선택한다. **미디어 도구**에서
로컬 파일 또는 완료 큐 파일을 선택하고 작업을 고른다. 준비가 끝나면 **결과 저장**을
누른다. 병합은 영상 파일과 음성 파일을 모두 선택해야 한다. 처리 중 취소할 수 있다.

원본 영상 다운로드는 고정 파일 용량·재생 길이·전체 준비 시간 제한 없이 디스크에 기록한다.
서버 지원·저장 공간·목록 8MiB/100,000개 자산 예산은 적용하며 상세 조건은
`LARGE_DOWNLOADS.ko.md`를 참고한다. MP3/M4A 오디오 다운로드 변환은 기존
입력 128MiB·출력 약 128MiB 미만·4,096조각·준비 5분 한도를 유지한다.
로컬 도구는 입력·출력 각각 256MiB(병합 입력은 두 파일 합계), 미디어 최대 10분,
실행 5분, 영상 한 변 8,192·전체 16,777,216픽셀 한도이다. 인코딩·컨테이너·메타데이터는
출력에 따라 달라진다. 자막·챕터·첨부·모든 다중 트랙/메타데이터 보존은 지원하지 않는다.
WebM은 현재 포함 코어에서 실제 검증한 VP8 인코더를 사용한다. VP9 인코딩은 해당 코어의
메모리 오류가 재현되어 제공하지 않는다. 원격 코덱이나 추가 서버를 내려받지 않는다.

복사한 주소는 만료되거나 원래 브라우저 로그인 세션을 필요로 할 수 있다. 쿠키를 함께
복사하거나 새 접근 권한을 만들지 않는다. 주소 복사 자체는 추출을 실행하지 않으며, YouTube 영상 페이지는 사용자가 다운로드를 요청한 뒤에만 별도 도우미로 추출한다.

원본의 YouTube 전용 추출기·서명 처리·2시간 제한 코드는 포함하지 않는다. 1.16.0의 YouTube 지원은 별도 유지보수되는 yt-dlp 2026.10.21·EJS 0.8.0과 로컬 Deno를 연동한 구현이다. 영상·음성의 제공 형식, 사이트의 추가 요구와 네트워크 조건에 따라 추출이 실패할 수 있다. 앱은 브라우저 쿠키를 자동으로 읽거나 도우미에 전달하지 않는다. DRM/암호화·로그인/유료 권한을 우회하거나 라이브·재생목록 일괄 처리를 제공하지 않는다. 만료된 주소는 원본 페이지에서 다시 추출한다.
실제 확장 API 통합은 클라우드 관리자 정책으로 설치가 차단되어 별도 환경 검증이 필요하다.
