## 검토와 승인

- `audit_lifecycle`: 기록·다운로드·서비스 워커·탭 수명주기 검토와 수정, 큐 격리 회귀 검사.
- `audit_native`: 백신 호스트·설치·Windows 어댑터 검토, ClamAV 암호화·진단 처리 수정과 실제 엔진 검증.
- `audit_media`: HLS/DASH·전송·미디어 도구 검토, DASH 수정과 실제 조각·계획 검사 준비.
- `audit_ui_package`: UI·접근성·설정·의존성·ZIP 검토, 비공개 설정 안내와 실제 패키지 작성기 회귀 검사.
- `audit_approval`: 위 담당들과 상호 확인하고 수정 범위·최종 diff·회귀 검사를 독립 검토했습니다. 코드 변경별 승인과 통합 검사 범위 승인을 받았습니다. 전체 실행과 배포물 검증 결과는 아래에 기록합니다.
- 주 에이전트: 통합 브라우저 회귀 검사, 문서·버전·최종 배포물과 GitHub 반영을 담당합니다.

에이전트의 승인은 기술 검토 결과입니다. 사용자 권한이나 운영체제·브라우저의 허가를 대신하지 않습니다.

현재 빌드·브라우저·HTTP/3 보고서의 공통 SHA-256은 `a48adbb5c2dc0c7549924f95d973ef2a6cfae079aeaa024415de060865b51c2b`입니다. 네이티브·실제 백신 보고서도 현재 호스트 소스 해시와 일치합니다. 기계 판독 결과는 `full-audit.json`, `browser.json`, `native-tests.json`, `antivirus.json`, `http3.json`, `npm-audit.json`에 있습니다.

다섯 ZIP의 무결성과 SHA256SUMS를 확인했습니다. 설치 ZIP은 현재 dist 24개 파일 및 버전 1.7.0과, 백신 도우미 ZIP은 현재 네이티브 파일 4개와, 소스 ZIP은 현재 프로젝트의 배포 대상 82개 파일과 바이트 단위로 일치합니다. 두 호환 별칭도 각각 같은 ZIP입니다. 메일·캐시·키 파일·생성 빌드·검증 출력은 소스 ZIP에서 제외합니다. 설치 ZIP의 FFmpeg·라이선스는 포함합니다.

최종 독립 기술 판정은 **APPROVE — My Video App 1.7.0**입니다. `audit_approval`이 현재 소스·보고서·다섯 ZIP의 파일 일치와 체크섬을 별도로 검증하고 커밋·업로드를 막는 미해결 문제가 없다고 승인했습니다.

## 검증 범위와 한계

브라우저 하네스의 Chromium·Worker·FFmpeg Wasm·OPFS·미디어 출력과 전체 디코드는 실제 실행입니다. Chrome 확장 API와 브라우저 안의 백신 포트는 대역입니다. 실제 unpacked 확장 설치는 관리 정책으로 차단되며 정책을 변경하지 않았습니다. Windows Security Center·COM·AMSI·Defender 분기는 Linux에서 대역으로 확인했고 실제 Windows PC에서 실행한 것으로 주장하지 않습니다.

실제 ClamAV 검사는 시험용 로컬 서명 DB를 사용하며 공식 DB의 최신성·전체 탐지 범위를 검증하지 않습니다. EICAR 문자열·서명 DB·암호화 시험 파일은 임시 디렉터리에서 제거하고 배포하지 않습니다. `npm audit`의 알려진 취약점 결과도 모든 코드·Wasm의 무결점 증명이 아닙니다.

사이트별 접근·로그인·서명·CDN, 모든 HLS/DASH 변형, 라이브·DRM·원본 전용 기능의 완전 동등성은 보장하지 않습니다. 파일은 디스크 저장 후 검사하며 별도 수동 선택 파일을 백신으로 검사하는 기능은 아닙니다. 지원 범위는 `LOCAL_MODE.ko.md`, 검사 시점·Windows 설치는 `SECURITY_DOWNLOADS.ko.md`, 상세 실행 범위는 `VALIDATION.ko.md`를 참고하세요.
